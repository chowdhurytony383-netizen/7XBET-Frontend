# Games files বাদ দেওয়া হয়েছে

এই zip ছোট রাখার জন্য `public/originals` এর বড় source-game/original-game files বাদ দেওয়া হয়েছে।

পরে বসানোর নিয়ম:

1. আপনার original frontend zip অথবা backup থেকে `public/originals` folder copy করুন।
2. এই project এর `7XBET-Frontend-main/public/originals/` folder এর ভিতরে paste করুন।
3. তারপর frontend deploy/build করুন।

Path ঠিক থাকবে:

```txt
7XBET-Frontend-main/public/originals/<game-folder>
```
